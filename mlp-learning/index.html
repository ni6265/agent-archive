4 · 实现用到的公式

下面就是页面里实际跑的代码逻辑（前向、损失、反向、更新），可直接对照浏览器里的脚本查看。

前向：zj = x₁·W(1)j1 + x₂·W(1)j2 + b(1)j，hj = ReLU(zj) = max(0, zj)
输出：z = Σj hj·W(2)j + b(2)，ŷ = σ(z) = 1 / (1 + e−z)
损失（二元交叉熵，N = 12）：L = −(1/N) Σ [ y·ln ŷ + (1−y)·ln(1−ŷ) ]
反向（对第 i 条样本，δ = ŷ − y）：
∂L/∂W(2)j = δ·hj，∂L/∂b(2) = δ
∂L/∂zj = δ·W(2)j·𝟙[zj > 0]，∂L/∂W(1)ji = ∂L/∂zj·xi，∂L/∂b(1)j = ∂L/∂zj
更新：W ← W − 学习率 × 平均梯度（偏置同理）

注意：ReLU 在 z ≤ 0 时导数为 0，该神经元本轮收不到梯度——这就是训练中“死神经元”的来源。本页的随机种子（30）选得让三个神经元初始时都在全部 12 条样本上活跃，训练 300 轮后仍各在 10–11 条样本上活跃，所以三个“朋友”都参与了学习。
